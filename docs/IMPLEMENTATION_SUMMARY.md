## 🎓 Curriculum System Features

### Supported Activity Types (8)
1. **TEXT** - Text-based learning content
2. **PDF** - PDF documents with audio narration
3. **AUDIO** - Audio content (with/without background music)
4. **VIDEO** - Video content (with/without background music)
5. **INTERACTIVE** - External interactive activities
6. **QUIZ** - Assessment quizzes with questions and answers
7. **BOOK** - Interactive books with multiple pages
8. **HOMEWORK** - Homework assignments with file uploads

### Curriculum Hierarchy
```
Curriculum (e.g., "Arabic Language")
  ├── Unit 1 (e.g., "Arabic Alphabet")
  │   ├── Lesson 1 (e.g., "Letter Alif")
  │   │   ├── Activity 1 (TEXT: "Read About Alif")
  │   │   ├── Activity 2 (AUDIO: "Listen to Alif")
  │   │   └── Activity 3 (QUIZ: "Alif Quiz")
  │   └── Lesson 2 (e.g., "Letter Ba")
  └── Unit 2 (e.g., "Arabic Words")
```

### Status Workflow
- **DRAFT**: Being created by admins, not visible to students
- **PUBLISHED**: Active and available to students
- **ARCHIVED**: Retired content, hidden from students

## 🔒 Security Implementation

### Authentication
- JWT-based stateless authentication
- Access tokens (24 hours)
- Refresh tokens (7 days)
- BCrypt password encryption

### Authorization
- Role-based access control (RBAC)
- URL-level protection (SecurityConfig)
- Method-level protection (@PreAuthorize)
- 5 distinct user roles

### API Security
| Operation | Allowed Roles |
|-----------|---------------|
| Create/Update/Delete Curriculum | SUPER_ADMIN, SCHOOL_ADMIN |
| Delete (any entity) | SUPER_ADMIN only |
| View Published Content | All authenticated users |
| View Draft Content | SUPER_ADMIN, SCHOOL_ADMIN, TEACHER |
