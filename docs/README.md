# Documentation - JeelEducation LMS

## Contents
This directory contains project documentation including:

- **API Documentation**: REST API endpoints, request/response formats
- **Database Schema**: Entity relationships, table structures
- **Architecture Diagrams**: System architecture, data flow
- **User Guides**: How to use the application (per role)
- **Developer Guides**: Setup instructions, coding standards
- **Deployment Guide**: Docker, AWS, Vercel deployment steps
