# User Database Schema

## Table: `users`

### Description
Stores all user information for the JeelEducation LMS system. Supports multiple user roles with role-based access control.

### Columns

| Column Name | Data Type | Constraints | Description |
|-------------|-----------|-------------|-------------|
| `id` | BIGINT | PRIMARY KEY, AUTO_INCREMENT | Unique user identifier |
| `username` | VARCHAR(50) | NOT NULL, UNIQUE | User's login username (3-50 chars) |
| `email` | VARCHAR(100) | NOT NULL, UNIQUE | User's email address |
| `password` | VARCHAR(255) | NOT NULL | Encrypted password (BCrypt) |
| `first_name` | VARCHAR(50) | NOT NULL | User's first name |
| `last_name` | VARCHAR(50) | NOT NULL | User's last name |
| `mobile` | VARCHAR(20) | NULL | User's mobile phone number |
| `role` | VARCHAR(20) | NOT NULL | User role (ENUM) |
| `is_active` | BOOLEAN | NOT NULL, DEFAULT TRUE | Account active status |
| `is_email_verified` | BOOLEAN | NOT NULL, DEFAULT FALSE | Email verification status |
| `is_account_non_locked` | BOOLEAN | NOT NULL, DEFAULT TRUE | Account lock status |
| `profile_picture_url` | VARCHAR(500) | NULL | URL to profile picture |
| `bio` | VARCHAR(1000) | NULL | User biography/description |
| `reset_password_token` | TEXT | NULL | Token for password reset |
| `reset_password_token_expiry` | DATETIME | NULL | Token expiration timestamp |
| `created_at` | DATETIME | NOT NULL | Account creation timestamp |
| `updated_at` | DATETIME | NOT NULL | Last update timestamp |
| `last_login_at` | DATETIME | NULL | Last login timestamp |

### Indexes

- **Primary Key**: `id`
- **Unique Index**: `username`
- **Unique Index**: `email`
- **Index**: `role` (for faster role-based queries)

### Role Enum Values

| Role Value | Display Name | Description |
|------------|--------------|-------------|
| `SUPER_ADMIN` | Super Admin | Full system access and management |
| `SCHOOL_ADMIN` | School Admin | School-level administration |
| `TEACHER` | Teacher | Curriculum and student management |
| `PARENT` | Parent | Child progress tracking |
| `STUDENT` | Student | Learning content access |

### Relationships

- Future relationships with:
  - `schools` table (for SCHOOL_ADMIN, TEACHER, STUDENT)
  - `students` table (for PARENT-STUDENT relationship)
  - `progress_tracking` table (for STUDENT learning progress)

### Notes

1. **Password Storage**: Passwords are stored using BCrypt encryption (minimum 8 characters)
2. **Email Verification**: New accounts have `is_email_verified = false` until email is confirmed
3. **Account Status**: Accounts can be deactivated (`is_active = false`) or locked (`is_account_non_locked = false`)
4. **Audit Trail**: `created_at`, `updated_at`, and `last_login_at` provide audit information
5. **Password Reset**: Uses token-based system with expiry timestamp
6. **JPA Auditing**: `created_at` and `updated_at` are automatically managed by Spring Data JPA

### Database Creation

The database will be auto-created when the application starts (if it doesn't exist) due to the configuration:
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/jeeleducation_lms?createDatabaseIfNotExist=true
```

The schema is auto-generated by Hibernate based on the entity definitions.
